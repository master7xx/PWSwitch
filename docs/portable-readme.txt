PWSwitch — Windows x64

РУССКИЙ
Запустите PWSwitch.exe и найдите его значок в трее Windows. В меню можно
выбрать схему питания, изменить время экрана и сна, открыть расширенные
настройки или выйти. Пункт «Язык» позволяет сменить язык интерфейса.
Автозапуск включается только по вашему выбору в меню. Перенос файла после
включения автозапуска может потребовать обновить путь в этом же меню.

ENGLISH
Run PWSwitch.exe and find its icon in the Windows notification area. Use the
menu to select a power plan, change display and sleep timeouts, open advanced
settings, or exit. The Language menu changes the interface language. Autostart
is optional and enabled only when selected. If you move the executable after
enabling autostart, update the path using the same menu.

ESPAÑOL
Ejecute PWSwitch.exe y busque el icono en el área de notificación de Windows.
El menú permite elegir un plan de energía, cambiar los tiempos de pantalla y
suspensión, abrir los ajustes avanzados o salir. El menú Idioma cambia el idioma
de la interfaz. El inicio automático es opcional y solo se activa si se elige.
Si mueve el ejecutable después de activarlo, actualice la ruta en el mismo menú.
